# SkyLimitless

Fabric mod for Minecraft 1.21.1 that will raise the vanilla world-height limit.

## Build environment

- Minecraft 1.21.1
- Fabric Loader 0.19.3
- Fabric API 0.116.15+1.21.1
- Fabric Loom 1.9.2
- Gradle 8.12
- Java 21

GitHub Actions builds the mod automatically on every push to `main` and on pull requests.
